# Card Element Gap Audit

The card catalog audit now includes a content-gap layer for planning new cards before creating assets or tuning balance. It reads existing CardScript effect lines, owned `CardElement`, card category, pack usage, role tags, status/summon/tile payload definitions, and generated rules text.

## New CSVs

All reports are written under `Saved/CardCatalog` when `UCardCatalogAuditTool::RunCardCatalogAudit()` exports balance reports.

- `CardElementCoverageAudit.csv`
  - One row per element, including Neutral.
  - Counts production spells, summons, traps, auras, role coverage, generators, payoffs, tactical cards, unique operations, status terms, missing card types, and missing roles.
  - Debug cards do not count as production coverage.

- `ElementPackGapAudit.csv`
  - One row per card pack.
  - Shows Neutral support count/weight, element pool count/weight, debug entries, off-element or mixed-element pools, role spread, repeated tactical fingerprints, missing card types, and recommended pack fixes.
  - Element packs should trend toward one non-neutral element plus Neutral support.

- `CardContentRecommendations.csv`
  - Actionable card ideas generated from current gaps.
  - Includes priority, element, suggested card type, role filled, intended operation/delivery/payload, draft rules text, and a draft card art prompt.
  - Prompts are planning text only; no prompt files or card assets are generated by this audit.
  - Once baseline coverage exists, the audit still emits medium/low lane-depth recommendations for thin identity coverage, such as Fire hazard pressure, Frost shield setup, Storm tempo tools, Nature growth defense, and Radiance healing/protection.

## Priority

- `High`: an element or element pack lacks a major card type or an entire core role.
- `Medium`: the role exists but is below the current target, such as only one generator or payoff.
- `Low`: useful variety after baseline coverage exists, especially lane identity reinforcement that is not blocking production.

## Element Lanes

- Fire: burn, hazard pressure, risk damage.
- Frost: freeze/root control, shielded setup, shatter payoff.
- Storm: chain, push/pull, movement, draw tempo.
- Nature: root, healing, shields, growth/sustain.
- Radiance: shield, heal, protection, smite payoff.
- Quietus: vulnerable, drain, death/reaping payoff.

## Workflow

1. Run the card catalog audit.
2. Open `CardElementCoverageAudit.csv` to find element-level gaps.
3. Open `ElementPackGapAudit.csv` to check whether each element pack has Neutral support and a focused element pool.
4. Use only the highest-priority rows in `CardContentRecommendations.csv` for the next card creation pass.
5. Prefer existing operations and status/tile/summon definitions before adding new effect vocabulary.

This pass is audit-only. It does not change card assets, packs, maps, widgets, Blueprints, costs, balance values, or gameplay behavior.
